Features

Everything a serious
LaTeX writer needs

No bloat. No distractions. A clean, capable workspace that stays out of your way.

⌨
Distraction-free editing
Monaco-style editor with full syntax highlighting, bracket matching, autocomplete for LaTeX commands, and a command palette.
◧
Real-time preview
Preview pane updates as you type with sub-200ms latency. Toggle auto-compile or trigger it manually — your call.
▤
Project file tree
Organize multi-file projects from a clean sidebar. Chapters, figures, bibliography — all in one structured workspace.
⊙
Snapshot versioning
Save named snapshots at any milestone. Restore or compare without touching Git. Never lose a day of writing to a bad edit.
✦
Inline AI assistant
Select any passage to improve, rewrite, shorten, or explain it — with AI that understands LaTeX context, inline, without leaving the doc.
⬡
Desktop & mobile
A desktop-first editor that collapses gracefully on mobile. Your workspace follows you from workstation to tablet.
